# UI: Authentication and Account Entry

See also:

- [UI index](../ui.md)
- [API auth](../api/auth.md)

The app starts with an auth screen.

## Auth Screen

- if no admin exists yet, the auth screen shows first-admin bootstrap
- normal accounts sign in by handle and password
- demo mode starts an ephemeral showcase session with no real writes

## Account Badge

- the top-right badge shows the current account
- the account menu provides logout
